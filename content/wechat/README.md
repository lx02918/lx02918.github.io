# 微信公众号文章存档

这里保存迁入博客的 8 篇公众号文章的可回查来源。每篇目录包含：

- `original.html`：从原公众号页面正文区域取得的 HTML，保留原始文字与排版标记；
- `article.md`：从 HTML 转换的可编辑 Markdown，保留原文链接与本地配图路径；
- `metadata.json`：标题、发布日期、原文地址、网站地址、配图清单和正文摘要校验值。

网站页面位于仓库根目录下相应的 `2026/` 日期路径。配图由微信图片地址下载到 `img/wechat/`，避免依赖微信图片热链。Markdown 是迁移转换稿，不是公众号编辑器的原始草稿；要核对转换差异，请以 `original.html` 和原文地址为准。
